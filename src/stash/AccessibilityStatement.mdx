This site aims to meet WCAG 2.1 Level AA. I test it with automated tools and by
hand, and I have not had it audited by an outside party. If something blocks
you, tell me and I will fix it.

## What is in place

- Semantic HTML with a logical heading order on every page.
- Every control works from the keyboard.
- ARIA attributes where plain HTML does not carry the meaning.
- Text contrast that meets WCAG AA in both the light and the dark theme.
- Layouts tested on phone, tablet and desktop screen sizes.

## How it is tested

- **On every change:** ESLint with the jsx-a11y rules.
- **On demand:** axe-core and Lighthouse run against the live pages in a
  browser. I run them by hand, not on a schedule.
- **By hand:** keyboard navigation and the browser's accessibility inspector.

## Latest audit results

The audit ran on 2026-10-04 against the home page, the demos page and the
stash page.

- axe-core found 0 violations across WCAG 2.1 A and AA.
- Lighthouse scored accessibility 1.00, 0.98 and 1.00, one score per page.

Automated tools catch only part of the problems a person can hit. These results
do not cover every page or every screen reader.

## Report a barrier

Message me on [LinkedIn](https://www.linkedin.com/in/cooper-reed/) or
[Bluesky](https://bsky.app/profile/cooperability.com). Name the page and what
got in your way. If you tell me which browser or assistive technology you were
using, that helps me reproduce it.
